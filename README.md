# B站视频搜索和评论工具

一个基于 bilibili-api-python 库的Python工具，可以根据关键词搜索B站视频，并在相关视频下发送评论。

## 版本说明

### v2 版本 (推荐)
- 文件：`main_v2.py`
- 特点：
  - 支持Windows控制台中文显示，解决了编码问题
  - 新增防重复评论功能，自动记录已评论视频
  - 新增评论历史查看和管理功能
  - 批量评论时自动跳过已评论视频
- 使用方法：`python main_v2.py`

### v1 版本
- 文件：`main.py`
- 特点：
  - 原始版本，在某些Windows控制台可能出现中文乱码
  - 同样支持防重复评论功能

## 功能特点

- 🔍 **关键词搜索**：根据用户提供的关键词搜索B站视频
- 📋 **结果展示**：清晰展示搜索结果，包括视频标题、UP主、播放量等信息
- 💬 **单条评论**：对单个视频发送评论
- 🚀 **批量评论**：支持对多个视频批量发送评论
- ⚙️ **配置管理**：自动保存登录凭证，避免重复输入
- 🛡️ **反爬机制**：内置请求延迟，避免触发B站风控
- 📝 **防重复评论**：自动记录已评论视频，避免重复发送相同评论
- 📊 **历史记录**：查看和管理评论历史记录

## 安装说明

### 1. 安装Python依赖

```bash
pip install -r requirements.txt
```

或者手动安装：

```bash
pip install bilibili-api-python aiohttp
```

### 2. 获取B站登录凭证

使用此工具需要B站的登录凭证，请按以下步骤获取：

1. 打开浏览器，访问 [B站](https://www.bilibili.com/) 并登录
2. 按 `F12` 打开开发者工具
3. 切换到 `Application`（Chrome）或 `存储`（Firefox）标签
4. 在左侧找到 `Cookies` -> `https://www.bilibili.com`
5. 找到并复制以下Cookie值：
   - `SESSDATA`
   - `bili_jct`
   - `buvid3`（可选）

## 使用方法

### 运行程序

```bash
python main.py
```

### 使用流程

1. **首次运行**：程序会提示输入B站登录凭证
2. **选择功能**：
   - 输入 `1`：搜索视频并评论
   - 输入 `2`：查看评论历史
   - 输入 `3`：清空评论历史
   - 输入 `4`：重新设置登录凭证
   - 输入 `5`：退出程序
3. **搜索视频**：输入关键词和要显示的视频数量
4. **选择视频**：输入要评论的视频编号（支持多选和范围选择）
5. **输入评论**：输入要发送的评论内容
6. **设置间隔**：设置评论发送的时间间隔（建议5秒以上）
7. **确认发送**：确认后开始批量发送评论
8. **防重复机制**：程序会自动检查视频是否已评论过相同内容，已评论的视频会被跳过

### 选择视频的格式

- 单个视频：`1`
- 多个视频：`1,3,5`
- 范围选择：`1-5`
- 全部视频：`all`

## 配置文件

### 登录凭证配置

程序会自动创建 `config.json` 文件保存登录凭证：

```json
{
  "sessdata": "您的SESSDATA",
  "bili_jct": "您的bili_jct",
  "buvid3": "您的buvid3"
}
```

### 评论历史记录

程序会自动创建 `comment_history.json` 文件记录评论历史：

```json
{
  "BV1xx411c7mD": [
    {
      "time": "2026-06-02 18:30:00",
      "comment": "评论内容",
      "title": "视频标题"
    }
  ]
}
```

该文件用于：
- 防止对同一视频重复发送相同评论
- 查看评论历史记录
- 批量评论时自动跳过已评论视频

## 错误处理

- **412 错误**：请求过于频繁，请增加发送间隔或使用代理
- **登录失败**：检查SESSDATA和bili_jct是否正确
- **评论失败**：可能视频关闭了评论功能，或账号被限制
