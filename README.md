# 使用示例

本文档基于最新版本，覆盖所有核心功能的使用流程。

---

## 一、启动工具

### 方式一：双击 exe（推荐）

- 双击 `B站评论工具.exe`
- 控制台窗口会显示 `Running on http://127.0.0.1:5000`
- 浏览器会自动打开（如未自动打开，手动访问 `http://127.0.0.1:5000`）
- 所有数据保存在 exe 同目录的 `user_data/` 下，下次启动数据不会丢失

### 方式二：源码运行

```bash
pip install -r requirements.txt
python app.py
```

---

## 二、登录 B 站账号

工具启动后，顶部导航栏右侧显示「登录」按钮。

### 扫码登录（推荐）

1. 点击「登录」→ 弹出登录弹窗
2. 默认就是扫码登录页，显示二维码
3. 用 B 站 App 扫码确认
4. 登录成功后弹窗自动关闭，顶部状态栏显示你的用户名和头像

### 手动 Cookie 登录

1. 登录弹窗中点击「手动 Cookie」标签
2. 粘贴 B 站登录后的完整 Cookie 字符串
3. 可自定义账号名称（方便多账号区分）
4. 点击确认

### 多账号管理

- 登录弹窗底部显示所有已保存的账号
- 点击任意账号可直接切换
- 点击删除按钮移除账号

---

## 三、搜索视频

1. 在顶部搜索框输入关键词（如「教程」「评测」「Vlog」）
2. 可选设置搜索排序：综合排序 / 最近发布 / 最多播放
3. 点击搜索或按 **Ctrl+K** 聚焦搜索框后回车

### 搜索结果

- 视频卡片展示：封面、标题、UP 主、播放量、发布时间
- 标题中搜索关键词自动蓝色高亮
- 点击「查看详情」查看完整描述和详细数据
- 已评论过的视频会显示「已评论」标识

### 过滤设置

搜索页面右上角可展开过滤条件：
- **排除已评论**：不显示已发送过评论的视频
- **过滤屏蔽词**：不显示标题含屏蔽词的视频
- **过滤黑名单 UP 主**：不显示黑名单中 UP 主的视频

---

## 四、发送评论

### 单条评论

1. 在搜索结果中找到目标视频
2. 点击视频卡片右侧的「评论」按钮
3. 输入评论内容（或选择已有模板）
4. 点击发送或按 **Ctrl+Enter**

### 模板评论

- 切换到「模板」Tab 页
- 点击已有模板 → 自动填入评论输入框
- 添加新模板：模板栏底部输入框 → 添加
- 删除模板：点击模板标签上的 ×

### 批量评论

1. 搜索结果中勾选多个视频
2. 点击底部出现的「批量评论」按钮
3. 弹出预览弹窗，确认要评论的视频列表
4. 选择评论模式：
   - **使用模板**：选择一个模板发送给所有视频
   - **变体发送**：为每个视频生成不同的评论变体
5. 确认发送，实时显示进度条

### 评论变体

勾选「使用变体」后，系统会为每条评论随机变换：
- 添加语气前缀（如"确实，""不得不说，"）
- 添加语气后缀（如"啊""呢""吧"）
- 变换标点（~ ～ ！ ... 等）
- 插入表情（😊👍🔥 等，按情感匹配）
- 尾部添加零宽字符（防重复检测）

**注意**：变体不改变原意，仅微调表达方式。

---

## 五、评论历史

点击顶部「历史」Tab 查看所有已发送的评论记录：

- 每条记录显示：视频封面、标题、发送的评论内容、时间、UP 主
- **再次评论**：点击某条记录右侧的「再次评论」按钮，用相同内容再发一次
- **批量再次评论**：勾选多条记录 → 底部「批量再次评论」→ 预览确认 → 发送
- **删除记录**：单条删除或全部清空
- **导出数据**：右上角可导出为 CSV 或 JSON 文件

---

## 六、屏蔽管理

切换到「屏蔽」Tab，包含两个子标签：

### 屏蔽词

- 添加关键词，搜索时自动过滤标题含该词的视频
- 支持添加 / 删除 / 一键清空
- 搜索时实时生效

### 黑名单 UP 主

- 添加 UP 主名称，搜索时自动过滤其视频
- 支持添加 / 删除 / 一键清空
- 搜索时实时生效

---

## 七、排除列表

「排除」Tab 展示所有已评论过的视频列表：

- 自动记录：每次发送评论后自动添加到排除列表
- 搜索结果中已排除的视频不再推荐
- 可手动删除排除项

---

## 八、回复评论

在搜索 Tab 底部可展开「回复指定评论」：

1. 输入目标视频的 **BV 号**
2. 输入要回复的 **评论 ID (rpid)**
3. 输入回复内容
4. 点击发送

---

顶部导航栏右侧有月亮/太阳图标：
- 点击切换深色/浅色模式
- 浏览器关闭后偏好保留

## 十一、常见问题

**Q: 扫码后没反应？**
A: 扫码后在手机 B 站 App 中确认登录。如仍无反应，点「重新生成」刷新二维码。

**Q: 发送评论提示失败？**
A: 
- 确认已登录 B 站账号（顶部状态栏显示用户名）
- 检查评论内容是否为空
- B 站每日评论数有限制，可能会触发风控

**Q: 搜索结果太少？**
A: 检查「过滤设置」是否过于严格（勾选了全部过滤项），尝试取消部分过滤。

**Q: 退出重进数据没了？**
A: 确保 exe 和 `user_data/` 在同一目录。新版本已修复此问题，数据会自动持久化。

**Q: 可以多人使用吗？**
A: 如果通过内网穿透暴露服务，每个浏览器窗口自动独立会话，各自登录自己的 B 站账号，互不影响。
