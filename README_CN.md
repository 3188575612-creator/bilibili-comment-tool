# B站视频搜索和评论工具

一个基于 bilibili-api-python 库的Python工具，可以根据关键词搜索B站视频，并在相关视频下发送评论。

## 功能特点

- 🔍 **关键词搜索**：根据用户提供的关键词搜索B站视频
- 📋 **结果展示**：清晰展示搜索结果，包括视频标题、UP主、播放量等信息
- 💬 **单条评论**：对单个视频发送评论
- 🚀 **批量评论**：支持对多个视频批量发送评论
- ⚙️ **配置管理**：自动保存登录凭证，避免重复输入
- 🛡️ **反爬机制**：内置请求延迟，避免触发B站风控
- 📝 **防重复评论**：自动记录已评论视频，避免重复发送相同评论
- 📊 **历史记录**：查看和管理评论历史记录

## 快速开始

### 1. 安装依赖

```bash
pip install bilibili-api-python aiohttp
```

### 2. 获取B站登录凭证

1. 打开浏览器，访问 [B站](https://www.bilibili.com/) 并登录
2. 按 `F12` 打开开发者工具
3. 切换到 `Application`（Chrome）或 `存储`（Firefox）标签
4. 在左侧找到 `Cookies` -> `https://www.bilibili.com`
5. 找到并复制以下Cookie值：
   - `SESSDATA`
   - `bili_jct`
   - `buvid3`（可选）

### 3. 运行程序

```bash
python main_v2.py
```

## 使用流程

1. **首次运行**：程序会提示输入B站登录凭证
2. **选择功能**：
   - 输入 `1`：搜索视频并评论
   - 输入 `2`：查看评论历史
   - 输入 `3`：清空评论历史
   - 输入 `4`：重新设置登录凭证
   - 输入 `5`：退出程序
3. **搜索视频**：输入关键词和要显示的视频数量
4. **选择视频**：输入要评论的视频编号（支持多选和范围选择）
5. **输入评论**：输入要发送的评论内容
6. **设置间隔**：设置评论发送的时间间隔（建议5秒以上）
7. **确认发送**：确认后开始批量发送评论
8. **防重复机制**：程序会自动检查视频是否已评论过相同内容，已评论的视频会被跳过

## 选择视频的格式

- 单个视频：`1`
- 多个视频：`1,3,5`
- 范围选择：`1-5`
- 全部视频：`all`

### 评论历史记录

程序会自动创建 `comment_history.json` 文件记录评论历史：

```json
{
  "BV1xx411c7mD": [
    {
      "time": "2026-06-02 18:30:00",
      "comment": "评论内容",
      "title": "视频标题"
    }
  ]
```

该文件用于：
- 防止对同一视频重复发送相同评论
- 查看评论历史记录
- 批量评论时自动跳过已评论视频

## 错误处理

### 常见错误码
- **-101**：登录凭证无效或已过期，请重新获取SESSDATA和bili_jct
- **-400**：参数错误，请检查评论内容
- **-403**：权限不足，账号可能被限制
- **-412**：请求过于频繁，请增加发送间隔或使用代理
- **12002**：评论区已关闭，该视频禁止评论
- **12009**：评论内容被过滤，可能包含敏感词
- **-1（有data字段）**：评论可能已成功发送，程序会自动识别

### 特殊情况：评论成功但显示失败
如果评论实际上发送成功了（B站上能看到评论），但程序显示失败（错误码-1），这是因为B站API返回了非标准格式。程序已更新判断逻辑，现在会自动识别这种情况。

详见：《评论成功但显示失败的说明.md》

### 排查步骤
1. 运行测试脚本：`python test_comment.py`
2. 查看详细的错误信息和解决建议
3. 参考《评论失败排查指南.md》

### 快速解决
- **登录失败**：重新获取SESSDATA和bili_jct
- **评论失败**：检查视频是否支持评论，增加发送间隔
- **风控问题**：等待一段时间后再试，或使用代理
- **显示失败但实际成功**：程序已修复，会自动识别非标准返回
